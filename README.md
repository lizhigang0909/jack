# ✦ Orbit · 星球任务站

一个轻量的中文待办与专注工具。给日常的小进步，一点宇宙的仪式感。

## 功能

- 添加、完成、删除任务，按状态筛选。
- 每项已完成任务提供 10 能量，每 50 能量解锁一个探索里程碑。删除或清理任务会移除对应能量。
- 15 / 25 / 45 分钟专注计时，支持暂停、继续和重置；根据实际时间计算，减少后台节流造成的漂移。
- 任务保存在当前浏览器的 localStorage，不需要账号或后端。清除浏览器数据会丢失任务。
- 响应式布局，键盘操作与屏幕阅读器标签支持。

## 本地运行

需要 Python 3，无第三方依赖。在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后在自己的浏览器访问 `http://127.0.0.1:8000`。请通过 HTTP 打开，以使用安全上下文下的任务 ID API。

## 结构

- `index.html`：页面与语义结构
- `style.css`：星球视觉、响应式样式
- `app.js`：任务管理、本地存储、专注计时

纯 HTML / CSS / JavaScript，无构建流程。也可部署到支持静态文件的网站服务，例如 GitHub Pages（从 main 分支根目录发布）。

计时器刷新后会重置，关闭网页后不会发送通知；应用不会上传你的任务数据。
