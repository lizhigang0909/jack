# 造物指南 · Codex 零基础项目指南

面向没有编程基础、希望用 Codex 创建自己项目的人。纯静态中文网页，无第三方依赖，不连接账号或外部服务。

## 包含内容

- 从需求到维护的 8 步流程，每步包含操作清单、可复制提示词、完成标准和常见坑。
- 28 个可搜索、按分类筛选的问答。
- 12 个常见技术词的普通话解释。
- 本机阅读进度，支持重置；复制功能不可用时提供手动复制提示。
- 手机适配、键盘可操作、状态提示。
- [纯文字完整版](GUIDE.md)，不启用 JavaScript 也可阅读。

## 如何打开

在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

在自己的浏览器访问 `http://127.0.0.1:8000/codex-guide/`。
云端运行时，localhost 属于云端机器，不能直接当作自己电脑的访问地址。

也可以交给静态托管服务发布。若通过 GitHub Pages 从仓库根目录发布，本项目位于发布网址的 `/codex-guide/` 路径。提交代码不会自动启用 GitHub Pages。

## 数据与限制

只有勾选的阅读进度使用 localStorage，属于当前浏览器和网站地址；更换浏览器、清除数据后不会同步。搜索内容不保存。不上传任何数据，不调用 Codex API，不自动创建或发布项目。

复制按钮通常需要安全上下文（HTTPS 或 localhost）与浏览器权限。受限制时会选中文本供手动复制。

文中提问模板供用户按实际需求修改。平台界面、套餐、可用工具与权限可能变化，需要以实际账号和当前服务规则为准。

## 文件

- `content.js`：流程、模板、问答和术语数据
- `app.js`：导航、进度、复制和搜索交互
- `style.css`：响应式界面
- `index.html`：页面结构
- `GUIDE.md`：与内容数据对应的纯文字版

修改内容后，请同步更新 GUIDE.md。无需构建即可运行。
